# A 股指数增强：风险模型与回测引擎（节选）

这是我个人 A 股量化研究代码库里两个自成一体的部分，用于中证 1000 指数增强产品。数据层、信号层、合成模型和组合优化器不在其中，可在面试中口头展开。

| 文件 | 内容 |
|---|---|
| `qlab/portfolio/riskmodel.py` | 日频多因子风险模型：每日截面回归估因子收益，指数加权因子协方差，按观测日估个股特质方差，残差主成分统计因子，按各因子持续性把协方差校正到持仓周期，以及按交易日缓存的逐日成员截面回归 |
| `qlab/barra.py` | 12 个风格因子的原料与标准化、正交化（CNE6 风格的子集，数据来源不含在内） |
| `qlab/backtest/engine.py` | A 股日频回测引擎：次日成交（收盘 / 开盘 / VWAP），涨跌停与停牌约束，佣金、印花税、过户费、红利税与实测成本面的拆分，退市处理；口径见文件头说明 |
| `qlab/data/panel.py`、`qlab/config.py` | 引擎依赖的两个数据结构（面板与成本配置） |
| `tests/test_engine.py`、`tests/test_engine_exec.py` | 回测引擎的合成数据测试：涨跌停与停牌下的成交规则、两段记账、费用与红利税、退市写掉 |
| `tests/test_riskmodel.py` | 风险模型的已知答案测试：合成数据上回收真实因子协方差与特质方差，停牌名字的特质方差不塌缩，日频与快照两条估计路径一致，Newey-West 不改水平，逐日缓存与窗内估计器一致，成员掩码把非成员的污染挡在因子协方差外 |

## 风险模型的校准方法

Barra 式偏差统计量：在 258 个测试组合（随机等权 200、风格倾斜 24、行业超配 29、信号篮子）加 10 个走产品优化器的组合上，每 20 个交易日重组，实现主动收益除以事前预测波动的标准差应为 1。只含行业与风格的基础模型中位数 1.11（风格倾斜 1.22，优化组合 1.08），终版 0.99（风格 0.99，优化 0.99）。

## 运行测试

```
pip install -r requirements.txt
pytest -q
```

文件里的数据路径常量指向本机数据盘，仓库不含数据；测试全部用合成数据。
